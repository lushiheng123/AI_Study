### Functional Requirements

- **FR-001**: System MUST support deployment across 5 controller nodes monitoring different server subsets
- **FR-002**: System MUST execute only read-only operations without 'stop', 'restart', 'shutdown', or 'reboot' commands  
- **FR-003**: System MUST use only shell commands (bash/sh) without Python dependencies for maximum compatibility
- **FR-004**: System MUST establish SSH-based connectivity from controller nodes to all target servers
- **FR-005**: System MUST implement type-specific monitoring for Compute (GPU/Docker/AI), DB (MySQL/MariaDB), Web (Nginx/Apache), Public (DNS/NTP/YUM), and Log nodes
- **FR-006**: System MUST perform basic system monitoring including uptime, memory usage (free -h), disk space (df -h), and CPU usage
- **FR-007**: System MUST verify network connectivity and reachability of all target nodes

*Example of marking unclear requirements:*

- **FR-008**: System MUST monitor service status via [NEEDS CLARIFICATION: specific service names and check methods not specified]

### Key Entities *(include if feature involves data)*

- **Controller Node**: Ansible controller that executes monitoring commands via SSH, manages subset of target servers
- **Target Server**: Monitored Linux system categorized as Compute, DB, Web, Public, or Log node type
- **Monitoring Result**: Collected metrics and service status from target servers
